# Веб-страница «Погода и новости»

Этот проект представляет собой веб-страницу, которая предоставляет пользователям актуальную информацию о погоде и связанных новостях для указанного города. Дизайн страницы выполнен с использованием HTML, CSS и Bootstrap, а логика для отображения данных предполагает интеграцию с серверной частью, написанной на Python (например, Flask или Django).

---

## Основные функции

1. **Поиск информации о погоде**:
   - Пользователь вводит название города в текстовое поле.
   - После отправки формы отображается информация о текущей погоде, включая температуру и описание состояния.

2. **Показ связанных новостей**:
   - Если для города доступны новости, они выводятся в виде списка ссылок.

3. **Интуитивный дизайн**:
   - Красивый фон (осенняя тема), адаптированный для отображения на всех устройствах.
   - Использование полупрозрачных контейнеров для улучшения читаемости текста.

---

## Используемые технологии

- **HTML5**: Разметка страницы.
- **CSS3**: Стилизация, включая фон и оформление элементов.
- **Bootstrap 4.5**: Для адаптивного дизайна и готовых UI-компонентов.
- **Jinja2 (шаблоны)**: Используется для динамического рендеринга данных на стороне сервера.
- **JavaScript**:
  - Подключение Bootstrap JS для улучшения интерактивности.

---

## Структура страницы

1. **Фон**:
   - Изображение `osen.jpg` в папке `static`.

2. **Заголовок**:
   - Отображает название «Погода в любой точке мира».

3. **Форма для ввода города**:
   - Поле для ввода названия города.
   - Кнопка отправки формы.

4. **Отображение результата**:
   - Информация о погоде (динамически рендерится, если данные доступны).
   - Список новостей (если новости для города доступны).

## Установка и запуск

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/<ваш-логин>/<репозиторий>.git
   cd <репозиторий>
   ```

2. **Установка зависимостей для серверной части**:
   Если используется Python, установите зависимости:
   ```bash
   pip install flask requests
   ```

3. **Запуск серверной части**:
   Предполагается, что логика обработки запросов реализована в Python:
   ```bash
   python app.py
   ```

4. **Открытие страницы в браузере**:
   Перейдите по адресу `http://127.0.0.1:5000`.

---

## Пример работы

### Ввод города
Пользователь вводит название города (например, «Москва») и нажимает кнопку «Узнать погоду».

### Результат
- Погода: Температура 15°C, облачно.
- Новости: Отображается список новостей, связанных с этим городом.
